================================================================================
SECURITY FEATURES EXPLAINED:
================================================================================

1. PASSWORD SECURITY
   - Never stored in plain text
   - Hashed with PBKDF2-SHA256 (industry standard)
   - Each password unique even if same text
   - Slow by design (resists brute force)

2. CSRF PROTECTION
   - Every form has unique CSRF token
   - Token validated on submission
   - Prevents malicious form submissions
   - Tokens expire with session

3. SQL INJECTION PREVENTION
   - Uses SQLAlchemy ORM (no raw SQL)
   - All queries parameterized automatically
   - Special characters escaped by database driver
   - Attackers can't inject SQL code

4. RATE LIMITING
   - Maximum 5 login attempts per IP per 5 minutes
   - Blocks after threshold exceeded
   - Prevents automated brute force attacks
   - Tracked per IP address

5. AUTHORIZATION
   - Every route checks user role
   - Students can't access landlord features
   - Landlords can't access admin features
   - Data filtered at query level

6. SESSION SECURITY
   - Secure flag (HTTPS only)
   - HTTPOnly flag (no JavaScript access)
   - SameSite=Lax (prevents CSRF)
   - Automatic expiration (7 days)

7. AUDIT LOGGING
   - All admin actions logged
   - Records: who, what, when, where (IP)
   - Admin can't modify own logs
   - Maintains accountability

8. INPUT VALIDATION
   - All inputs validated before storage
   - Regex patterns for usernames/phones
   - Email format validation
   - Length limits on text fields

9. ERROR HANDLING
   - No stack traces shown to users
   - Generic error messages
   - Errors logged for debugging
   - Professional error pages

10. SECURE DEFAULTS
    - Listings hidden until admin approval
    - Students auto-verified, landlords need approval
    - Users are active by default (can be banned)
    - Soft deletes maintain data integrity

QUICK START GUIDE:
================================================================================

1. INSTALL PYTHON
   - Download from python.org
   - Add to PATH (IMPORTANT!)

2. SETUP PROJECT
   mkdir room-radar
   cd room-radar
   # Copy all files here

3. CREATE VIRTUAL ENVIRONMENT
   python -m venv venv
   venv\Scripts\activate  # Windows
   source venv/bin/activate  # macOS/Linux

4. INSTALL DEPENDENCIES
   pip install -r requirements.txt

5. SETUP ENVIRONMENT
   copy .env.example .env  # Windows
   # Edit .env and set SECRET_KEY

6. INITIALIZE DATABASE
   python -c "from app import app, db; app.app_context().push(); db.create_all()"

7. RUN APPLICATION
   python app.py
   # Visit http://localhost:5000

8. LOGIN
   Email: admin@roomradar.local
   Password: Admin@1234
